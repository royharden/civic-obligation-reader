# Design references

The adopted plan credits Lawglass, LQ.AI and law-map for the general ideas of source-linked legal-text reading and version-aware presentation, and the portfolio S12/S27/S37/M3 designs for exact offsets, deterministic normalization, cost reservations and evaluation separation. These are design references, not vendored implementations or claims about current external products.

This repository implements its own small SHA-256/canonical JSON, Gregorian date arithmetic, seeded randomness, number words, span matching and cost arithmetic. No code was copied from other application repositories in this construction run. No external dependency or provider behavior has been verified by runtime execution.
